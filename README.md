# EMCICT311 - Student Grade Calculator

## 1. Project Description
A web-based Student Grade Calculator built with HTML5, CSS3, and JavaScript ES6.
It calculates Total, Average, Grade, and Status for students based on 3 assessment scores. Data is saved using localStorage.

## 2. Key Features
- Add multiple students with 3 scores each
- Automatic calculation using OOP Class
- Input validation to prevent errors and crashes
- Displays results in a responsive table
- Delete student records
- Data persists after page refresh

## 3. Technologies Used
- HTML5: Structure
- CSS3: Styling and Responsiveness
- JavaScript ES6: OOP, Loops, Conditionals, DOM
- localStorage: Data Persistence
- GitHub Pages: Deployment

## 4. How to Run
1. Clone the repo or download files
2. Open `index.html` in any modern browser
3. Enter student name and 3 scores
4. Click "Calculate & Save"

## 5. Grading System
| Average Score | Grade | Status |
| --- | --- | --- |
| 70 - 100 | A | Pass |
| 60 - 69 | B | Pass |
| 50 - 59 | C | Pass |
| 45 - 49 | D | Fail |
| 40 - 44 | E | Fail |
| 0 - 39 | F | Fail |
